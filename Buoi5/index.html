Nội dung học tập hôm nay:
  • Responsive Web Design: Kỹ thuật thiết kế giao diện tự động thích ứng với nhiều kích thước màn hình (Desktop, Tablet, Mobile) mà không bị vỡ bố cục hoặc cần zoom[cite: 4, 11].
  • CSS Flexbox Layout: Ôn tập các thuộc tính định vị linh hoạt (`display: flex`, `flex-wrap`, `justify-content`, `align-items`) và shorthand `flex` để xây dựng layout responsive[cite: 26, 29, 30].
  • Twitter Bootstrap 5 & Grid System: Sử dụng hệ thống lưới 12 cột (`.col-`, `.col-sm-`, `.col-md-`, v.v.) kết hợp với các thành phần như Navbar, Jumbotron để tối ưu hóa tốc độ phát triển giao diện[cite: 38, 45, 58, 67].
