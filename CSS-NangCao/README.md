## Mục tiêu
Thực hành document flow, position, z-index, float/clear, multi-column layout, responsive design, CSS transforms/transitions/filters/animations và Bootstrap 3.

## Cấu trúc
- `index.html`, `style.css`: portfolio và mục lục bài tập.
- `Lab07/Exercise01` → `Exercise19`: **19** bài riêng, mỗi bài có `index.html` và `style.css`.
- `Lab07/Exercise12`, `Lab07/Exercise13`: có thêm `desktop.css`, `mobile.css`.
- `assets/`: ảnh SVG tự dựng minh họa; hình đại diện là **chữ viết tắt**, không phải ảnh cá nhân.
- `bootstrap/`: Bootstrap v3.4.1 + JS và jQuery để dùng offline.

## Nhóm bài
| Exercise | Nội dung |
|---|---|
| 7.1–7.4 | document flow, relative/absolute positioning, z-index |
| 7.5–7.9 | float left/right, container clearfix, nhiều item, clear, overlay caption |
| 7.10–7.13 | hai/ba cột, media query tách CSS, viewport, menu mobile |
| 7.14–7.18 | rotate/skew/translate/scale, transitions, filter, @keyframes |
| 7.19 | Bootstrap 3.4.1: grid, navbar, panel, jumbotron, list-group, button |

## Kiểm tra
1. Vào `CSS-NangCao/index.html`, chọn từng Exercise.
2. Thử 390px và 1280px với 7.7 / 7.10–7.13 / 7.19.
3. Di chuột lên 7.14–7.16; quan sát filter 7.17 và animation 7.18.
4. Kiểm tra links, CSS local và thư mục Bootstrap; nếu deploy trong repo cũ không thay đổi các thư mục đã có.
